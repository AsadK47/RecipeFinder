# Security

RecipeFinder keeps your recipes on your device and in your own iCloud. If you find a way that could expose a
cook's data or weaken the app, please tell us privately so it can be fixed before it is public.

## Reporting a vulnerability

- Use GitHub's **Report a vulnerability** button on this repository's Security tab (private vulnerability
  reporting), or
- email **recipefinderuk@gmail.com** with "Security" in the subject.

Please include the app version (Settings → About), what you did, and what happened. We aim to reply within
7 days and keep you updated until the fix ships. Credit is given in the release notes if you'd like it.

## Supported versions

Fixes go into the latest App Store and TestFlight build.
