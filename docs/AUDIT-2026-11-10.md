# App audit — 2026-11-10

Two read-only code audits (per-feature UX + overall feel/tabs/new features). Bugs are from reading code, not device-confirmed.
Scores: **Usability 7/10 · Habit/delight 4.5/10.**

## 0. Likely bugs (one "Bug sweep" batch)
1. No UI sets pantry expiry/quantity — `addInventoryItem`/`updateInventoryItem` never called (KitchenInventoryManager.swift:114,141); expiry alerts + "use it up" can't work.
2. Remove-from-collection swipe dead: `.swipeActions` in ScrollView/LazyVStack (CollectionDetailView.swift:68).
3. ½× servings → 0 for 1-serving recipes (RecipeServingsCard.swift:82).
4. "Add week to groceries" ignores planned servings (MealPlanningManager.swift:256).
5. "Shopping list reminders" toggle unused (NotificationSettingsView.swift:51).
6. Share inbox holds one item; second share overwrites first (SharedImportInbox.swift:23-56).
7. Share sheet says "Recipe saved" before the app may reject it (ShareViewController.swift:131).
8. File import save failure only logged, no alert (ContentView.swift:126-129).

## 1. Biggest wins
1. **Tabs: Today · Recipes · Plan · Groceries · Me.** Import → "+" on Recipes + share extension + clipboard-link card; Settings → gear in Me (stats, badges, streak, diary). Today = Tonight hero (planned meal or pantry match, big Cook button), shelves (Cook again, Fits your fridge, New imports, Rediscover). Absorbs "Recently cooked row", "What's for dinner?", "Cooking diary".
2. **Made it = real celebration**: motion, count-up, variable "fun fact", distinct haptic vocabulary (94/181 haptics are `.light()`); more motion craft (only 3 symbolEffect uses). Streak chip visible at 0 ("Start a streak").
3. **Grocery → Kitchen loop**: "Put away" bought items (with expiry) instead of deleting (ShoppingListManager.swift:283); To buy | At home switcher; empty-state CTAs (Add this week's plan / staples). Fixes bug 1.
4. **Cooking mode**: several named timers, swipe between steps, step's own ingredients, confirm + resume on Done, timer presets, voice-command hint.
5. **Recipes home**: drop A–Z default (recent/most-cooked), search ingredients/tags/cuisine, visible filter chip row, "missing: eggs" on can-make cards, richer long-press menu, empty state with Import button.
6. **Planning**: week agenda by default, tap meal → open/cook, cooking marks planned meal done, per-meal servings, pinned "Shop for this week".
