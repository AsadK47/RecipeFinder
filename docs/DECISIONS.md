# Decisions — why things are the way they are

Durable record of choices made while building RecipeFinder: options rejected, tradeoffs accepted, constraints
discovered. Newest first. Each entry moves here from `WORK.md` Decisions when its item lands, so the reasoning
survives after the handoff is cleared. Read the entry for an area before "fixing" something that looks odd there.

## Item decisions
- **CookingResume seam host test** (5ec7f83, `agent/cooking-resume-host`, red check `agent/cooking-resume-host-red` = view reads
  `.shared`, must fail): hosts the real CookingModeView in a UIWindow with a fake `CookingResuming` (first view-hosting
  unit test). Chosen over "log the gap" because the gap is exactly the mutation reviewers named. **Pre-mortem:** (1)
  onAppear/onDisappear never fire offscreen → waitUntil times out, asserts fail (red run tells); (2) flaky under the
  XCTest stall → 5 s poll; (3) shared CookingSession/idle timer leak → onDisappear ends both.

- **NotificationManager seam:** a struct of three closures (not a protocol over `UNUserNotificationCenter`): matching
  the SDK's `@Sendable` completion signatures by retroactive conformance is brittle under Swift 6. Only `.shared`'s
  initializer makes it the center's delegate, so a test instance can't steal tap routing (`sharedInstanceRoutesTaps`).
  7 uncalled helpers (daily reminder, immediate, shopping update, cancel-all/timers, pending, badge) deleted rather
  than seamed (both reviewers flagged them uncovered; YAGNI). Tap routing stays untested
  (`UNNotificationResponse` can't be built). **Pre-mortem:** (1) the seam drops a request on the floor → every
  scheduler test asserts one request added; (2) a reminder asks for permission it shouldn't (or stops asking) →
  `asks` count per scheduler; (3) the real app stops routing taps → `sharedInstanceRoutesTaps`. Gap: the `.system` adapter is never run by a test.
- **Vegan seed methods (Chapati, Chai):** reworded to plant versions (vegan butter or oil; plant milk) rather than
  untag — both are vegan at heart and the dairy was optional/serving-only. Test checks every vegan-tagged bundled
  recipe's steps with `DietaryInference.containsAnimalProduct`; recipes titled "Vegan" skipped (author's dairy words

  `veganSeedMethodsArePlantOnly`; (3) curated/seed drift → `committedCatalogMatchesGenerator`.

- **Theme palette (slice 1, landed a45fecd):** text on accent fills is white (`AppTheme.onAccent`) — 12 sites used
  adaptive black, which failed on the deeper accents; Dark gradients deepened to L 0.28→0.15 so Dark accents are ≥3:1
  on every stop (they were ~2:1). Themes defined in OKLCH, not sRGB, so accents share one perceived lightness per mode
  (L 0.52 light / ~0.56 dark) and gradients step lightness on one hue family (±20°). Accent luminance is pinned to the
  window where white text is ≥4.5:1 *and* the dark accent is ≥3:1 on the dark base — so accents are deeper than before
  (Honey reads as amber, not lemon: yellow can't carry white text). Light gradients went lighter (L 0.82→0.66) so black
  text is ≥4.5:1 on every stop (old teal end was ~4:1). Light accent vs the Light gradient is 1.8–3.2:1 (old teal
  1.0–2.0) — 3:1 would need near-white gradients; recorded in CHALLENGES. Gold+Yellow merge into Honey; old names map in
  `ThemeType(storedValue:)` and ThemeStore writes the new name back. Hue degrees in the item are HSL; code uses OKLCH
  hues (Tomato 30 … Raspberry 358). **Pre-mortem:** (1) a saved theme resets to Teal on update → `oldNamesMigrate` +
  `migratesOldName`; (2) an accent fails contrast / clips out of gamut → per-theme contrast + gamut tests;
  (3) a gradient looks muddy or text vanishes on it → black/white-on-every-stop tests + 61/62 screenshots in both modes.

## Constraints discovered
- Files in the repo can be bundled app resources (`screenshots/home_page.png` was): before deleting any non-.md file, `grep` it in `project.pbxproj` — a dangling Resources entry breaks the build (main went red 2026-11-10, fixed on `agent/fix-home-png`).
- New Swift files must go in the **app** target's Sources phase (first mirror attempt landed in the share extension).
- Auto-mode blocks force-push (even with owner OK), remote branch deletes and some rm; land branches by merging main into them (no rewrite), and ask owner to delete stale `agent/*` branches.
- Screenshot UI tests share simulator data: open seeded recipes by name, not `firstMatch`.
